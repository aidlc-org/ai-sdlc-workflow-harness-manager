# UI designer policy (configurable)

| Attribute | Value |
|-----------|--------|
| Type | Policy |
| Audience | Parent (copies values into `route.md`) |
| Adapt | Edit the table columns only. Do not add extra classes. |

Owned by **feature-development**. Parent applies this **after** PM returns
(`prd.md` exists) and **before** spawning `ui-designer-agent`. Then write or
update `skip_ui_designer` in `features/{slug}/route.md`. Honor
[next-agent-policy.md](next-agent-policy.md) for legal `next_agent` values.

Edit the `run_ui_designer` column only. Do not invent extra classes.

| Class / workflow | run_ui_designer | What runs when true |
|------------------|-----------------|---------------------|
| micro | false | Never |
| minor | false | Never |
| jira-bug | false | Never |
| feature (text-sourced feature-development) | true if any **run trigger** below matches | `ui-designer-agent` then combined `@signoff:requirements` |
| jira-story / jira-epic | false unless the customer chain lists `ui-designer-agent` | Optional overlay; kit default chain does not insert it |

Defaults: UI designer is **off** for micro, minor, and bugs. On feature-class
**text** work it runs when a user-facing surface exists.

## Run triggers (any one → run)

Read `prd.md` (and PM `context.next_agent`). Run UI designer if **any** match:

- New route, page, screen, or information architecture
- PRD surfaces include web, mobile, desktop, ERP, portal, or mixed
- User-facing flows (forms, dashboards, approvals, catalogs) in the to-be journey
- PM `context.next_agent` is `ui-designer-agent`
- User typed `RUN_UI_DESIGNER: true`

Skip UI designer on feature class when **none** of those match (API-only,
CLI, batch/job, no screens) and the user did not force it. If PM set
`next_agent: signoff-requirements` **and** no hard trigger matches, skip.

## One-run override

If the user types `RUN_UI_DESIGNER: true` or `RUN_UI_DESIGNER: false`, that
wins for this `route.md` only. Do not edit this file for a one-off.

`CONSULT_UI: true` does not flip `skip_ui_designer`. It only allows a
**consult insert** after Architect or BA (see next-agent-policy).

## Parent mapping

- `run_ui_designer: true` → `skip_ui_designer: false` and keep `ui-designer-agent` before `@signoff:requirements`
- `run_ui_designer: false` → `skip_ui_designer: true` and drop that step; requirements sign-off is PRD-only

Architect policy still runs **after** `@signoff:requirements`.
